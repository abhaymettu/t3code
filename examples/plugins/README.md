# Example plugins

Each folder is a complete plugin. Copy one into `~/.t3/userdata/plugins/`, then turn it on in
**Settings → Plugins**. The guide is [docs/user/plugins.md](../../docs/user/plugins.md).

- `backdrop`: a picture behind the whole window, with settings for fade, the sidebar, and which part of
  the picture stays in view. Replace `backdrop.webp` with your own image and update the `url()` in
  `backdrop.css`.
- `thread-details`: one switch per thread details section, to hide the ones you do not use.
